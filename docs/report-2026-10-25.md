## 三、前端交互问题与改善方案

现状：架构底子是好的（投影纯函数、SSE 解析器独立、文案集中、有离线演示），但交互层确实粗糙。按严重程度分级：

### P0 —— 功能性 bug（应先修，约半天）

1. **中文输入法回车误发送**（`PlaygroundPage.tsx:159`）：只判断 `e.key === "Enter" && !e.shiftKey`，拼音候选确认的 Enter 也会把消息发出去。修复：

   ```tsx
   onKeyDown={(e) => {
     if (e.nativeEvent.isComposing) return;
     if (e.key === "Enter" && !e.shiftKey) { e.preventDefault(); submit(); }
   }}
   ```

2. **取消后界面卡死在流式态**（`useRunStream.ts:79`）：`cancel()` 只是 abort，`projection.phase` 停在 `"streaming"`，光标永久闪烁。`copy.playground.cancelled` 文案已定义但从未使用。修复：新增 `cancelled` 终态分支，终态栏显示"已取消"。
3. **滚动打架**（`PlaygroundPage.tsx:75`）：每个 `lastSeq` 变化都触发 `scrollIntoView({behavior:"smooth"})`，流式期间每秒几十次平滑滚动；用户上翻阅读会被强行拽回底部。修复：sticky-bottom 策略——只有当前贴近底部（距底 < 50px）才跟随，流式时用 `behavior:"auto"`，并在上翻时显示"回到底部"悬浮按钮。

### P1 —— 体验硬伤（约 1.5 天）

4. **无 Markdown 渲染**：回答按纯文本展示，代码块/列表/加粗全露标记，这是 AI 控制台最大的观感短板。引入 `react-markdown` + `remark-gfm` + 代码高亮；recharts 已占 bundle 大头，建议同时把 recharts 改为路由级动态 import，守住 250KB 预算。
5. **消息列表性能**：`key={i}` 用数组下标且列表每 delta 全量重渲染。给每条消息稳定 key + `React.memo(ChatMessageView)`；长会话再上虚拟列表（`@tanstack/react-virtual`）。
6. **失败无重试**：错误栏只展示 code/message，后端已返回 `retryable` 字段但 UI 没用。加"重试"按钮，直接复用最后一轮输入重新 `send()`。
7. **usage 徽标闪现即逝**：completed 后立即 `invalidate + reset()`，本轮 token 统计立刻消失。把 usage 并入该轮的历史渲染或延迟清理。
8. **输入区**：textarea 固定 2 行不自适应增高；流式期间打字后点发送被静默丢弃（`submit` 直接 return）。自适应高度（`field-sizing-content` 或手动 setHeight）+ 流式时按钮态明确。
9. **反馈体系缺失**：Key 创建/复制/撤销、会话创建全靠内联文字或原生 `window.confirm`。引入轻量 toast（如 sonner）+ AlertDialog 替换原生确认框。
10. **401 后静默跳登录**：key 被撤销后用户只看到跳转，不知原因。跳登录时带一条提示（`copy.login.authFailed` 文案已备未用）。

### P2 —— 打磨（约 1 天）

11. 骨架屏替代全局 Spinner；Sessions 页无搜索/删除/重命名、裸 UUID 直接展示；Usage 页应即改即查（去掉独立"查询"按钮）并加汇总卡（总 tokens/runs）；环图只统计了 `input_tokens`；Status 页后台刷新无指示。
12. 无响应式：侧栏固定 `w-52`，移动端完全不可用（至少加个折叠）；无 ErrorBoundary（渲染异常直接白屏）；无快捷键（`/` 聚焦输入、`Ctrl+K` 切会话）。
13. 工具卡展开只能看参数看不到**结果**——需要后端在 `tool.completed` 事件或 audit 查询里透传结果预览，属于前后端协同项。
14. 动效基调：目前只有 `transition-colors`。低成本高感知：消息入场 fade+slide（纯 CSS animation）、工具卡展开高度过渡、按钮 `active:scale-95`。

### 与 main 控制台的对比（合流时参考）

main 版（gzip 79.5KB）更轻，但功能少：没有离线演示模式、没有 SSE 重连处理；它独有的"key 一键绑定 Playground"体验值得搬到 zh 版。zh 版 bundle 194.63KB 主要被 recharts 占用，合流后优先做 code-split。
